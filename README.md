# Excellent plugins for Claude

This repository is a Claude plugin marketplace. It holds one plugin, [`excellent`](excellent/README.md),
which connects Claude to [Excellent](https://beexcellent.ai), the operating platform for restaurant groups,
and adds everyday workflows: answering a private-dining inquiry, booking it into a room, the week ahead,
the pre-shift note, staffing the week, assigning training, invoicing an event, and thank-you cards.

```
/plugin marketplace add ethicalfrei/excellent-claude-plugin
/plugin install excellent@excellent
```

See [`excellent/README.md`](excellent/README.md) for what the plugin does, what it never does, and how it
handles data. Licensed MIT.

This folder is the source of truth in the Excellent repository; the public repository is a mirror of it.
